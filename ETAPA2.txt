Sausage Run 3D - Etapa 2 (Unity 6)

1. Extraia este ZIP na raiz da pasta do projeto (a que contem Assets).
   O script fica em Assets/_SausageRun3D/Scripts/Player/ScoobyController.cs
2. Verifique se o pacote Input System esta instalado (Window > Package Manager).
   Em Edit > Project Settings > Player > Active Input Handling, selecione
   Input System Package (New) ou Both, se necessario.
3. Na cena Sala, expanda SausageRun_Prototipo > 05_Scooby_Maria_Bolinha,
   localize o marcador azul de Scooby e desative somente esse marcador.
4. Na Hierarchy (raiz da cena), crie um Empty com nome Scooby:
   Position = (2.5, 0.05, -7.1), Rotation = (0,0,0), Scale = (1,1,1).
5. Em Scooby, Add Component > Character Controller:
   Center = (0,0.325,0), Height = 0.65, Radius = 0.22,
   Step Offset = 0.15, Skin Width = 0.03.
6. Arraste ScoobyController.cs para Scooby no Inspector.
7. Desative a Main Camera antiga na raiz (desmarque o checkbox do objeto).
8. Clique direito em Scooby > Camera; renomeie como CameraScooby.
   Transform local: Position = (0,0.48,0), Rotation = (0,0,0), Scale=(1,1,1).
   Ajuste Field of View = 75, Near Clipping Plane = 0.03.
   Certifique-se de que a nova Camera tenha Tag = MainCamera e Audio Listener.
9. Pressione Play e clique na janela Game para capturar o mouse.
   WASD: mover; Shift: correr; Espaco: pular; Mouse: olhar; Esc: liberar mouse.
10. Salve a cena (Ctrl + S) depois de sair de Play Mode.

Este script nao implementa escalada, IA, bolinha nem vitoria. Essas sao etapas seguintes.
